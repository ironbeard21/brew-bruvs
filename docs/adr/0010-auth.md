# 0010. Authentication: local accounts plus optional OIDC

- Status: Proposed (maintainer to accept)
- Date: 2026-11-21

## Context

Self-hosters need simple accounts out of the box, and many already run single sign-on (Authentik, Authelia, Keycloak). Phone apps need long-lived sessions.

## Decision (proposed)

Local email-and-password accounts with a first-run admin setup, plus optional OIDC login configured by environment variables. Sessions stored in Postgres; phone apps use revocable tokens. Personal API tokens with scopes for integrations. Library: evaluate Better Auth (TypeScript, Drizzle support, OIDC) in issue P0-07 against writing a minimal session layer; pick the simpler one that passes the tests.

## Consequences

Works with no external services; SSO users can plug in their provider. The library choice is confirmed when P0-07 merges.
