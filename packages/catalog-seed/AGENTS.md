# AGENTS.md — packages/catalog-seed

Adds to the root `AGENTS.md`. Lead: Codex. Reviewer: Claude.

Holds the open-licensed seed catalog (hops, fermentables, yeasts, misc, styles, water profiles, equipment) and the importer that loads it into the database.

## Layout

```
data/              CSV + catalog.json, sources.csv, build_report.csv (generated; do not hand-edit)
build/             build_catalog.py: rebuilds data/ from the upstream repos
LICENSES/          upstream license texts
ATTRIBUTION.md     credits shown in the app's About page
src/import.ts      loads data/ into the database (pnpm seed)
```

## Rules

- `data/` is generated by `build/build_catalog.py`. To change data, change the script or the upstream source, rebuild, and commit both.
- The importer is idempotent: running `pnpm seed` twice leaves the database unchanged. Upsert on the catalog `id`.
- Every catalog row keeps `sources`, `licenses` and `aliases` in the database; search matches aliases.
- Only add sources with an AGPL-compatible open license (AGPL, GPL-3.0, MIT, BSD, CC0, CC-BY, CC-BY-SA). Add each one to `SOURCES` in the build script, `ATTRIBUTION.md` and `LICENSES/`.
- Never import style description text from BJCP or the Brewers Association; names, IDs and numeric ranges only.
- Community edits made in the app are stored separately from seed rows, so a rebuild never overwrites them.

## Tests

- Importer test: load into an empty database, check row counts match `build_report.csv`, run again, check nothing changed.
- Spot-check test: a fixed list of known items (Citra, Columbus with CTZ/Zeus aliases, WLP001, EC-1118, BJCP 2021 21A) loads with expected values.
